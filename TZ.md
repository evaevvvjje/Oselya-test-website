## 2. Технічні вимоги

### 2.5 Доступність і якість
- Семантична розмітка: `header`, `nav`, `main`, `section`, `footer`, правильна ієрархія `h1`→`h6` (один `h1`).
- `alt` українською для всіх змістовних зображень; декоративні — `alt=""`.

## 3. Дизайн-система

### 3.1 Кольори

Структура токенів повторює референс (surface / text / muted / accent / dark / border), значення — нові. Основа — світла тема з глибоким смарагдовим акцентом.

```css
:root {
  /* Поверхні */
  --color-surface:        #FFFFFF;   /* було white */
  --color-surface-2:      #F1F4F2;   /* було #efefef — світла секція */
  --color-dark:           #14211C;   /* було #211d1d — темні секції, футер */

  /* Текст */
  --color-text:           #14211C;   /* було #211d1d */
  --color-text-muted:     #55625C;   /* було #555 */
  --color-text-on-dark:   #FFFFFF;
  --color-text-on-dark-muted: #B8C4BE;

  /* Акцент (було #f7413e, червоний) */
  --color-accent:         #1E6B52;   /* кнопки, бейджі, активні стани */
  --color-accent-hover:   #175641;
  --color-accent-active:  #124636;
  --color-accent-soft:    #DDEBE4;   /* фон бейджів, іконок */
  --color-on-accent:      #FFFFFF;

  /* Лінії */
  --color-border:         rgba(20, 33, 28, 0.14);       /* було #211d1d24 */
  --color-border-on-dark: rgba(255, 255, 255, 0.14);    /* було #ffffff24 */

  /* Статуси форми */
  --color-error:          #B3261E;
  --color-success:        #1E6B52;
}
```

Правила:
- Акцент **не** використовується для великих фонів, лише для кнопок, малих плашок, іконок, цифр і підсвітки.
- Темні секції — тільки `--color-dark`; не вводити інших «майже чорних».
- Жодних кольорів поза цією таблицею, жодних дефолтних кольорів Tailwind.
- Градієнти — лише затемнення на фото (`from-black/60` до прозорого) і ледь помітний шум/зерно на темних фонах. Без «декоративних» кольорових градієнтів.

### 3.2 Шрифти

Референс: Bebas Neue (стиснутий капс) + Geist. Замінюємо на пару, що **гарантовано підтримує кирилицю**, включно з `і ї є ґ`:

| Роль | Шрифт | Ваги | Примітка |
|---|---|---|---|
| Заголовки (display) | **Unbounded** | 500, 600 | Широкий геометричний; на відміну від вузького Bebas, тому розміри нижче зменшені |
| Основний текст, кнопки, форми | **Onest** | 400, 500, 600 | Нейтральний гротеск |

```html
<link rel="preconnect" href="https://fonts.googleapis.com">
<link rel="preconnect" href="https://fonts.gstatic.com" crossorigin>
<link href="https://fonts.googleapis.com/css2?family=Onest:wght@400;500;600&family=Unbounded:wght@500;600&display=swap" rel="stylesheet">
```
```css
--font-display: "Unbounded", "Arial Black", sans-serif;
--font-body: "Onest", Arial, sans-serif;
```

Заголовки пишуться **звичайним регістром** (не капс). Фолбек-стеки обов'язкові.

### 3.5 Форма елементів

| Елемент | Значення |
|---|---|
| Кнопки | Повністю заокруглені (pill, `9999px`), padding 1rem 1.75rem, мін. висота 3.25rem |
| Кнопка primary | Фон `--color-accent`, текст `--color-on-accent`, hover `--color-accent-hover` |
| Кнопка secondary | Прозорий фон, рамка 1px `--color-border` (на темному — `--color-border-on-dark`), текст у колір секції |
| Картки | Радіус `--radius-medium` (1.5rem), рамка 1px `--color-border` |
| Поля форми | Радіус `--radius-xsmall` (0.625rem), висота 3.5rem, рамка 1px `--color-border`, фокус — рамка `--color-accent` |
| Зображення в картках | Радіус `--radius-medium` (1.5rem), `object-fit: cover` |
| Великі блоки (hero-панель, фото проєктів, pill-фото в CTA-банері) | `--radius-large` (2rem) або `--radius-xlarge` (2.5rem); pill-фото в CTA — `--radius-full` |
| Бейджі | Pill, фон `--color-accent-soft`, текст `--color-accent` |

**Токени радіусів — взяті з референсу без змін:**
```css
--radius-xsmall: 0.625rem;
--radius-small:  1rem;
--radius-medium: 1.5rem;
--radius-large:  2rem;
--radius-xlarge: 2.5rem;
--radius-full:   9999px;
```
> Який саме радіус стоїть на якому елементі референсу, у CSS не видно. Те, що вказано в таблиці вище, — найближче за змістом призначення; на кроці порівняння зі скріншотами (§6) за потреби замінити на сусідній токен із цієї шкали, не вигадуючи нових значень.

**Тіні** (багатошарові, з кольоровим відтінком, низька непрозорість; плоского `shadow-md` немає):
```css
--shadow-elevated: 0 1px 2px rgba(20,33,28,.06), 0 12px 32px -12px rgba(20,33,28,.18);
--shadow-floating: 0 2px 4px rgba(20,33,28,.08), 0 24px 48px -16px rgba(20,33,28,.28);
```
Шари глибини: base (поверхня) → elevated (картки) → floating (липка шапка, випадаючі елементи).

### 3.6 Іконки
Inline SVG, лінійний стиль, товщина штриха 1.5px, `currentColor`, розмір 24px (у картках переваг — 32px у колі `--color-accent-soft`). Потрібні: телефон, стрілка вправо, стрілка вгору-вправо, плюс/мінус (акордеон), пауза/плей, хрестик і бургер (мобільне меню), галочка, іконки послуг (будинок, диван, кухня, ванна), іконки переваг (команда, матеріали, задоволення клієнта).

### 3.7 Рух

- Easing: `cubic-bezier(0.22, 1, 0.36, 1)` (пружний вихід). Тривалість: hover 200–250ms, поява 600–700ms.
- Анімуються **лише `transform` і `opacity`**. `transition-all` заборонено.
- Поява при скролі (IntersectionObserver): елемент `opacity 0→1` + `translateY(24px→0)`, stagger 80ms між сусідніми елементами. Один раз на елемент.
- Завантаження сторінки: hero з послідовною появою (бейдж → H1 → кнопки → підзаголовок).
- Кожен елемент, що клікається, має стани **hover, focus-visible, active** — без винятків:
  - кнопки: hover — фон світлішає/темнішає за токеном + `translateY(-1px)`; active — `translateY(0)` + `scale(.98)`;
  - картки з фото: hover — зображення `scale(1.04)` усередині `overflow-hidden`;
  - посилання: підкреслення з'являється через `transform: scaleX` псевдоелемента.

**Поведінка — ефект стопки при скролі:** картки проєктів «накладаються» одна на одну. Коли користувач гортає вниз, наступна картка виїжджає знизу й перекриває попередню, і так з усіма трьома.
- Кожна картка — `position: sticky`; `top` = висота шапки + 1.5rem (на mobile + 1rem). `z-index` зростає від першої картки до третьої.
- Між картками в звичайному потоці — відступ `--gap-large`; висота картки на desktop не більша за висоту вʼюпорту мінус шапка, щоб картка повністю читалася, коли «прилипла».
- Поки наступна картка накриває попередню, попередня трохи зменшується й притемнюється: `transform: scale(1 → 0.94)` і `opacity` 1 → 0.6. Прогрес рахується через `scroll` + `requestAnimationFrame` (або `IntersectionObserver`), анімуються **лише `transform` і `opacity`**.
- `position: sticky` не працює, якщо в предків секції стоїть `overflow: hidden/auto/scroll` — замість цього використовувати `overflow: clip` або не ставити overflow зовсім.
- Якщо картка на mobile вища за вʼюпорт, для неї `position: relative` (без прилипання), щоб контент не обрізався.
- `prefers-reduced-motion: reduce` — без sticky і без масштабування, картки просто йдуть одна за одною.

**Поведінка:** кнопки-заголовки з `aria-expanded`, `aria-controls`; клавіатура Enter/Space. **Виняток із правила «лише transform/opacity»:** розкриття панелі через `grid-template-rows: 0fr → 1fr` + `opacity`, 300мс.

## 6. Порядок роботи

1. Прочитати `TZ.md`, `CLAUDE.md`, викликати skill `frontend-design`.
2. Запустити `node serve.mjs` у фоні (якщо ще не запущений).
3. Створити каркас: `<head>` (шрифти, мета, Tailwind config), токени з §3, базові стилі, Header і Footer.
4. Додавати секції **по одній** у порядку §4.0. Після кожної — скріншот (`node screenshot.mjs http://localhost:3000 назва-секції`), порівняння зі скріншотом референсу з `assets/references/`, виправлення.
5. Генерація зображень за §5 і підстановка замість заглушок.
6. Анімації: поява при скролі, лічильники, слайдер, marquee, акордеон.
7. Адаптив: окремий прохід по ширинах 375 / 768 / 991 / 1440.
8. Фінальна перевірка за чеклістом §8.

**Порівняння з референсом:** мінімум **2 раунди** на кожну секцію. Порівнювати розкладку, пропорції, відступи, розміри пропорційно до шрифтів (тексти й кольори свідомо відрізняються). Формулювати відхилення конкретно: «зазор між картками 16px, має бути ≈24px».

## 7. Заборони

- Не додавати секцій, функцій і тексту, яких немає в цьому ТЗ.
- Не «покращувати» референс — повторювати його структуру.
- Не використовувати emoji, `style=""`, `transition-all`.
- Не використовувати дефолтні кольори Tailwind і кольори поза §3.1.
- Не використовувати шрифти, окрім Unbounded і Onest.
- Не залишати `href="#"`, `lorem ipsum`, англійські тексти в інтерфейсі.
- Не переносити з референсу рекламні плашки шаблону і підписи Webflow/Reddevs.
- Не зупинятися після першого скриншота.
- Не змінювати тексти з цього ТЗ без запиту.
